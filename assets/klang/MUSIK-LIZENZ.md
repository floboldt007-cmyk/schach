# Lobby-Musik

Die Lobby-Musik besteht aus zwei getrennten Teilen:

| Was | Datei | Lizenz |
|---|---|---|
| Abspieler (Web-Audio-Oszillatoren, Planer, Ein- und Ausblenden) | `js/musik.js`, `js/pakete/musik/` | GPL-3.0 wie der ganze Code (siehe `LICENSE`) |
| Melodien (Tempo, Grundton, Klangfarbe, Tonfolge der fünf Weltstimmungen) | `assets/klang/melodien.json` | eigene Werke von Flo, alle Rechte vorbehalten, Nutzung nur in Crownmate (siehe `assets/LIZENZ-KUNST.md`) |

Der Vorbehalt gilt nur für die Melodie-Datei. Der Code, der sie abspielt, enthält keine Noten und steht ohne
Einschränkung unter der GPL-3.0. Wer den Code weitergibt, darf ihn mit eigenen Melodien in derselben Form benutzen.

Die Melodien sind selbst geschrieben. Es werden keine fremden Musikstücke, Aufnahmen oder Samples verwendet.

Stand: vorläufige Festlegung (Variante b aus der Prüfung vom 30.10.2026). Flo kann sie ändern, etwa die
Melodien ebenfalls unter die GPL-3.0 stellen; dann entfallen der Eintrag in `assets/LIZENZ-KUNST.md` und
der Vorbehalt in dieser Datei.
